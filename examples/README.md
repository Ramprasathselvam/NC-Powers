# Examples

This directory contains examples of how NC-Powers is intended to be consumed.

Examples should demonstrate workflow usage without exposing application source code or credentials.

Recommended examples include:

- `Implement <JIRA-KEY>`
- `Validate <JIRA-KEY>`
- `Create PR for <JIRA-KEY>`
- `Review PR for <JIRA-KEY>`
- `Complete <JIRA-KEY>`

Keep real project-specific class names, paths, tickets, screenshots, credentials, and internal URLs out of reusable examples unless they are intentionally public and approved.
